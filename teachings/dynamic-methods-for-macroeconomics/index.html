Dynamic Methods for Macroeconomics

Graduate course materials on differential equations, dynamic systems, optimal control, and dynamic programming.

Instructor: Arturo López (Teaching Assistant)

Term: Spring

Location: Centro de Investigación y Docencia Económicas (CIDE)

Level

Graduate (Maestría en Economía)

Course Overview

These materials develop the mathematical tools used to formulate and solve dynamic macroeconomic models. Topics include ordinary differential equations, linear and nonlinear dynamic systems, phase diagrams, difference equations, optimal control, and dynamic programming.

The files remain in their original classroom language.

Problem Sets and Quizzes

Week Topic Materials
Problem Set 1 Classification and solution of first-order differential equations, initial-value problems, and long-run behavior. Problem Set · Solution

Problem Set 3 Higher-order differential equations as linear systems, fundamental solution sets, Wronskians, and phase portraits. Problem Set and Solution

Problem Set 7 Infinite-horizon optimal control, a Ramsey model with endogenous labor, and finite-horizon dynamic programming. Problem Set
